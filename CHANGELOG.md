# Changelog

All notable changes to Pet Quest Legends will be documented in this file.

## [1.0.0] - Initial Release

### Core Features
- **Pet System**
  - 50+ unique pets across 6 worlds
  - 5 rarity tiers (Common to Mythical)
  - Pet merging system
  - Pet abilities (Fire, Flying, Ice, Shadow)
  - Pet following system
  - Visual effects based on rarity

- **World System**
  - 6 unique worlds to explore
  - Progressive unlock system
  - World-specific pets and eggs
  - Themed environments
  - Coin spawning system

- **Quest System**
  - Daily quests with 24-hour reset
  - World-specific quest chains
  - Achievement system
  - Legendary quests for mythical pets
  - Quest progress tracking

- **Guild System**
  - Create and join guilds (up to 50 members)
  - Guild contribution system
  - Guild levels and rewards
  - Guild-exclusive pets
  - Guild leaderboards
  - Rank system with permissions

- **Trading System**
  - Safe pet trading between players
  - Trade value calculator
  - Anti-scam protection
  - Trade confirmation system
  - Trade history tracking

- **Monetization**
  - 6 gamepasses (VIP, 2x Hatch Speed, 3x Coins, Auto-Hatch, Extra Pet Slots, Fast Travel)
  - 3 premium egg types (Galaxy, Rainbow, Shadow)
  - Temporary boosts (2x Coins, 2x Luck, 2x Hatch Speed)
  - Pet skins and cosmetics

- **UI System**
  - Main HUD with coins and level display
  - Notification system
  - Navigation buttons
  - Responsive design
  - Smooth animations

- **Data Management**
  - ProfileService integration
  - Auto-save every 5 minutes
  - Session locking
  - Data reconciliation
  - Safe shutdown handling

### Technical Features
- Rojo project structure
- Modular code architecture
- Client-server separation
- Remote event management
- Anti-exploit measures
- Performance optimization

### Known Issues
- UI placeholders need full implementation
- Pet models are basic spheres (need custom models)
- Some advanced features need polish
- Tutorial system needs implementation

### Planned Updates
- Weekly pet additions
- New worlds every 2-3 weeks
- Weekend events
- Seasonal updates
- Additional gamepasses
- More quest types
- Guild wars system
- Prestige system expansion
